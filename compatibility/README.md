# 구버전 호스트와의 전송 호환성

여기의 소스는 Suite 적용 전 설치본의 전송 형식을 보존합니다. Suite에 별도 플러그인으로 설치하지 않습니다. 구버전 Settings Sync가 자기 자신을 교체하지 않는 특성을 고려하여, 암호화된 백업에는 기존 형식의 호환 플러그인을 전달하고 Suite 호스트는 이를 세 플러그인으로 정규화합니다.

이 계층은 구버전 호스트의 UI·인증 전달 기능을 보존하기 위한 배포 어댑터입니다. 새 기능과 일반 수정은 `plugins`에서 진행합니다. 호환성 수정이 필요할 때만 이 계층을 수정하며, `baseline.json`은 최초 소스의 해시를 기록합니다. 계정 정보와 개인 설정은 포함하지 않습니다.
