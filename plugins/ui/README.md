# Paseo UI

전역 탭, 제목 표시, 호스트 순서, 기록 불러오기, 터미널 대화 화면을 한 플러그인으로 관리합니다. 각 구현은 `modules/tabs`, `modules/titles`, `modules/hosts`, `modules/import`, `modules/terminal`로 나뉩니다.

기존 ID `terminal-tabs`와 저장 키를 유지합니다. `paseo-ui` 호스트 설정에는 각 모듈의 활성 상태만 추가하며, 이전 제목 설정은 같은 값으로 옮깁니다. 제목·호스트 순서 설정 화면의 예전 주소는 본체 alias 확장이 이어 줍니다. 서버 재시도, 운영체제 표시, 기본 렌더링은 본체가 담당합니다.

전역 탭의 닫기·복원은 이 모듈이 담당하고, 파일·브라우저·터미널 탭 복원과 닫힌 탭의 순서는 본체가 담당합니다. 두 종류가 같은 이력을 사용하여 가장 나중에 닫은 탭과 원래 전역 위치를 복원합니다.

빌드·설치·검증은 [저장소 README](../../README.md)를 따릅니다. 개별 모듈의 기존 소스와 호환성 검사는 이전 버전 동작을 검증하는 기준으로 유지합니다.

자동 사용량 조회가 없는 구버전 본체에서는 열린 사용량 화면을 1분마다 다시 조회합니다. 서버의 5분 캐시를 유지하며, 본체가 자동 조회를 지원하면 호환 타이머는 해당 조회를 건너뜁니다. 다른 앱에서 작업하는 동안에도 갱신하며, 사용량 화면이 닫혔거나 호스트 연결이 끊어지면 조회하지 않습니다.
